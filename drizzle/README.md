# Migrations

Generated by `npm run db:generate` from `src/db/schema.ts`. Apply with `npm run db:migrate`, which uses `DATABASE_URL_UNPOOLED` from `.env.local`.

- `0000_baseline`: the schema as it was before migrations existed (created with `db:push`).
- `0001_recipients_and_send_chunks`: replaces to/cc/bcc with one canonical `recipients` list and adds `send_chunks`. It refuses to run while `drafts`, `revisions` or `sends` have rows, because the old rows can't be converted.

## Databases that were created with `db:push`

Those databases already have the baseline tables but no migration journal, so `db:migrate` would try to create them again and fail. Record the baseline as applied once, then migrate:

```sql
CREATE SCHEMA IF NOT EXISTS drizzle;
CREATE TABLE IF NOT EXISTS drizzle.__drizzle_migrations (id SERIAL PRIMARY KEY, hash text NOT NULL, created_at bigint);
INSERT INTO drizzle.__drizzle_migrations (hash, created_at)
VALUES ('e40bc445fa839657408c55442b8fb80b9b1d324ea4c0e6d15fb68f15617d882d', 1792773383292);
```

The hash is `shasum -a 256 drizzle/0000_baseline.sql` and `created_at` is its `when` in `meta/_journal.json`.

Then delete the old test rows (child tables first) and run `npm run db:migrate`:

```sql
DELETE FROM sends; DELETE FROM reviews; DELETE FROM revisions; DELETE FROM drafts;
```
